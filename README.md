# DentalAI Manager v2

Versión integrada con interfaz CustomTkinter y conexión a SQLite.

## Ejecutar

```bash
pip install -r requirements.txt
python app.py
```

## Módulos conectados

- Dashboard y contadores reales
- Pacientes: alta, edición, eliminación y búsqueda
- Importación JSON y exportación Excel
- Informes clínicos PDF
- IA clínica y guardado de análisis
- Historial IA, cambios de estado y PDF
- Estadísticas

El módulo de prescripciones queda preparado como siguiente fase, ya que no existía una implementación funcional en la versión original.
